# STXBP1-epiPred

Github repository for:
EpiPred: A gene-specific machine learning model for classifying missense variants in the epilepsy-related gene STXBP1
Jeffrey D Calhoun, Chengbing Wang, Carina Biar, Jonathan R Gunti, John Lee, Aaron M Geller, Jung H Hong, Santiago Schnell, Louis T Dang, Yu Wang, Jack Parent, Lori L. Isom, Michael D Uhler, Heather C. Mefford, M. Elizabeth Ross, Vanessa Aguiar-Pulido, Gemma L Carvill
bioRxiv 2025.08.09.669488; doi: https://doi.org/10.1101/2025.08.09.669488

Please see Data folder for the STXBP1 variants evaluated with feature annotations.

Please see Scripts folder for related Python notebooks. epiPred_STXBP1.ipynb contains code for supervised learning using scikit-learn. epiPred_STXBP1_SHAP.ipynb contains code for SHAP analysis.
